# Claude Desk

面向 Windows 的本地 Claude Code 工作空间。无需注册 Claude Desk 账号；直接使用本机官方 Claude CLI 及 `~/.claude/settings.json` 中的服务商配置。

## 启动

打包版：双击 `ClaudeDesk.exe`。选择项目文件夹，输入任务即可。

源码版：安装 Node.js 后运行 `npm ci`，再运行 `npm start`。

需要官方原生 Claude CLI：`%USERPROFILE%\.local\bin\claude.exe`。客户端优先使用这个路径。客户端不安装、修改或替换你的 Claude 配置。

## 交互

- 启动默认进入主页，不自动打开项目或旧会话；在主页手动选择项目，在左侧点击已有会话继续。点击“新任务”回到主页。选择项目之前不会自动创建空白会话。
- 首页输入框固定在底部，项目选择和轻量快捷建议保留在中间；会话内显示回复与项目文件面板。
- 左侧添加项目、搜索和切换会话，Ctrl+N 回到新任务主页。点击项目只选择项目，不创建空会话；首次发送非空消息后才创建会话，重复发送有防抖保护。
- 每轮回复底部可“删除这轮”；左侧会话行悬停或键盘聚焦后显示删除按钮，可删除整个会话。两种删除均使用应用内深色确认弹窗，默认聚焦取消，Esc 或点击外部取消。运行时先停止才能删除某轮；删除整个会话会停止该会话的任务。删除记录不会回滚项目文件。
- 删除某轮后会关闭旧 CLI，上下文从剩余问答重建；删除会话也会移除该会话草稿，恢复备份同步更新，避免普通恢复把已删记录带回。
- 点击模型按钮先打开紧凑思考面板：当前强度、模型名称与蓝色五档滑块；点击模型名称展开模型列表，选择后返回思考面板。模型列表支持搜索、刷新和自定义模型 ID。点击外部或输入框关闭；Esc 从列表返回思考面板，再按 Esc 关闭。切换应用时关闭。
- 输入 `/` 选择本地命令，`@` 引用项目文件，`@@` 引用其他已有会话；在输入框首行 / 末行按上下键召回当前会话的已发送消息。引用会作为上下文明确发送给 Claude。
- 中间显示 Markdown 回复、工具调用及输出。工具请求需要批准时，在输入框上方显示批准卡片。
- 底部运行条展示真实阶段、累计耗时和最后事件时间；25 秒无事件时明确说明正在等待，不虚构生成进度。
- 发送键左侧的圆环显示上下文占用百分比；点击查看上下文 tokens、CLI 返回的上限、剩余空间和统计模型。使用最近主会话响应的输入、缓存读取、缓存写入及输出 tokens，不累加整段会话的请求总量。数据缺失显示“—”；草稿、下一次请求和服务商账户余额不在统计内。
- 输入框 Enter 发送、Shift+Enter 换行；运行中 Enter 是插话（不停止任务，下一步之前交给 Claude），Tab 加入队列，输入框为空时发送键变为停止键。停止会终止该会话的 Claude 进程。
- 右侧查看 Git 改动与文本 diff，或浏览本地文件。它不会自动提交、暂存或回滚你的代码。
- 权限菜单包括“手动批准”“允许编辑”“仅做计划”“自动审批”“未授权即拒绝”“完全访问”六种模式。默认手动批准；自动审批需要 CLI、模型和服务商支持，不可用时保留 CLI 返回的具体原因。“完全访问”是显式选择的高级模式，跳过常规权限提示；其他模式不会设置 SDK 的跳过权限标志。已有权限规则及组织策略仍可能限制操作。设置从下轮消息开始生效。
- 设置面板显示 CLI、服务商和配置位置；可从已有服务商读取模型列表。密钥保留在主进程和现有 CLI 配置中，不进入渲染界面。

## 会话与上下文

每个活跃会话使用独立、持续运行的 Claude CLI 子进程，连续消息复用该进程上下文。不会使用临时 HOME，也不依赖第三方客户端创建的 resume ID。

项目、聊天、草稿、引用和模型选项统一保存在 `%APPDATA%\ClaudeDesk\data\workspace.json`。正式版始终使用这个目录，不受预览环境变量影响。写入先同步到临时文件，再原子替换，并保留上一份有效 `.bak` 备份；启动时可恢复完整的临时存档或有效备份，文件损坏时不会静默覆盖历史。

主页默认不选中历史记录，这不表示旧记录被删除；左侧“全部项目”可显示所有历史。未发送草稿随所属会话保存，主页草稿独立保存。首次升级会合并已知旧版预览目录里的记录并按会话 / 消息 ID 去重。

应用关闭会停止活跃任务。重新打开后，手动选择历史会话继续，或停止后继续、切换模型/权限/思考深度时，会从本地保存的对话重建上下文；界面标记“从本地历史恢复上下文”。恢复上下文最多保留约 120,000 字符，之前的完整记录仍可浏览和导出。

第一版不包含云同步、后台开机启动、浏览器控制、语音、图片附件或编辑器自动补全。Git 面板展示整个项目当前改动，不声称这些改动全部由本次任务产生。

## 常驻信息框与子智能体

右上角常驻显示“输出内容、来源、子智能体”。正文和输入框为信息框预留宽度，信息框不覆盖文字；文件、来源和子任务内容在框内滚动。来源汇总本会话引用的 @ 文件及 @@ 会话。

Claude 的 Agent / Task 调用会创建独立的子任务记录，按 parent_tool_use_id 分流输出与工具调用，任务生命周期、后台状态、进度和用量由 CLI 事件更新。子智能体详情可展开，嵌套任务有标记。主回复完成后若仍有子任务运行，客户端继续显示运行状态。

多个并行权限申请会排队展示，标明子智能体来源，批准一个不会自动批准其他请求。停止会话会终止其 CLI 并标记子任务已停止；重启后原来仍在运行的子任务显示已中断，保留其已有输出。CLI 没有提供的子任务输出、进度或用量不会补造。

子智能体卡片在折叠时也显示最新进展、最近工具 / 目标和耗时。主页汇总全部会话里仍在运行的子智能体；进入会话后显示该会话的完整子任务记录。主页卡片详情中可进入所属会话。没有真实任务时显示明确的空状态，不展示预览数据。

## 插件、技能和累计用量

左下角新增“插件、技能、用量”入口，在统一的管理窗口切换。

- 插件：读取本机 Claude CLI 的已安装插件和市场目录，支持搜索、按名称安装、添加 HTTPS / GitHub 市场、启停、更新及卸载。卸载保留插件持久数据；客户端不自动确认市场声明的安装命令，也不代填登录或密钥。需要这些流程的插件会显示 CLI 返回的原因。
- 技能：发现用户、当前项目和已启用插件的技能。可新建、导入包含支持文件的技能文件夹；本应用副本可编辑和移除，外部技能只读。技能库通过本地插件 `desk-user-skills` 加载，选择“全部”或“只加载所选”。修改后下一次发送会重建 CLI 并恢复聊天上下文，当前运行不重启。技能选择不是文件沙箱。
- 累计用量：按今天、7 天、30 天或全部时间，结合项目筛选；展示输入 / 输出 / 缓存读写 tokens、估算费用、按模型汇总和日期趋势，可导出 CSV。新版采用 SDK modelUsage 的增量统计，包含其报告的子任务消耗。旧记录和只返回主任务计数的 CLI 标记为明细不完整。统计仅覆盖本应用实际保存的事件，不代表服务商账单或账户额度。
- 删除会话或某轮问答后保留不含聊天正文的用量计数；模型名称、时间、项目 ID 和计数用于筛选，不保存提示词、回复或密钥。

### v0.9.0：统一会话数据
正式数据位于 `%USERPROFILE%\.claude-desk\data`，避免 AppData 在打包应用子进程中重定向到另一副本。`workspace.sqlite` 是权威存储，WAL + FULL 同步事务保存；每个会话独立一行，仅更新变化记录；`sessions` 保留当前会话 JSON 副本。删除会话或轮次写入无正文的审计记录，独立副本同步清理。启动不会从副本自动复活已删除记录。
首次迁移合并旧正式目录和 Codex 包缓存目录，保留较新内容、草稿和用量；`migration-backup.json` 是迁移前的完整快照，之后不会随删除更新。旧 JSON 保留用于回退，旧版软件不认识新数据库，请只用新版。设置页展示数据库、数据集 ID、版本和会话数量，并可备份全部数据。SQLite 损坏时保留原件并报错，不自动清空或回退到旧记录。


### v0.9.1：独立子智能体窗口
点击右侧子智能体卡片，在独立窗口查看任务、状态、文本输出、CLI 返回的思考内容和工具记录。多任务可分别开窗，同任务重复打开聚焦现有窗口。支持复制输出、跟随输出与返回主会话；关闭查看窗口不停止任务。审批仍在主会话完成。历史子任务从 SQLite 原记录打开，不创建新会话。窗口只展示 CLI 实际返回的信息，不能直接给已委派的任务发送新消息。


### v0.10.0：应用内分栏与 Codex 历史导入
子智能体卡片默认在右侧标签页打开，主对话保留在左侧；支持多标签、关闭、拖动调整分栏宽度及移到独立窗口。分栏复用实时任务记录，不创建额外会话或执行新任务。

Codex 分页日志：按 history_base 链递归读取指定字节范围，遵守回退边界；基础日志不存在或没有可定位范围时报错，不静默导入残缺对话。内部 guardian 审批会话不列入用户导入列表。

### v0.11.0：更接近 Codex 的体验
- 对话流：每轮按真实顺序记录说明文字、思考和工具调用。最终回复之前的过程折叠为「已处理 3m 12s · N 个步骤」，运行中自动展开。工具按 Codex 风格显示为「运行 `命令`」「读取 文件」「编辑 文件 +12 −3」（可展开行级 diff）「搜索」「更新计划」（清单）等。回复下方汇总本轮改动的文件，点击「审查改动」在右侧打开对应 diff。旧记录和 Codex 导入的会话同样适用。
- 侧栏：会话挂在所属项目下，项目可折叠，项目旁「＋」直接在该项目新建任务。会话的「⋯」菜单支持重命名（也可双击顶部标题）、置顶、归档和删除；底部「已归档」查看和恢复归档会话。
- 运行中继续发消息：任务运行时按 Enter 会把消息加入该会话的队列，本轮正常完成后自动发送。出错或停止时队列保留，可「立即发送」（先停止当前运行）、「编辑」或删除。输入框为空时发送键才是停止键。
- 图片附件：在输入框粘贴截图、拖入图片或点图片按钮添加（PNG/JPEG/GIF/WebP，每张 ≤ 5 MB，每条最多 6 张）。原图保存在数据目录的 attachments 中，以图片块发送给 Claude；消息里显示缩略图，点击用系统程序打开。删除会话或该轮问答时一并删除图片。重建上下文时历史只记录图片数量，不重发图片。
- 改动审查与提交：右侧「改动」按文件显示新增 / 修改 / 删除和 +/− 行数，可逐个或全部暂存，可撤销单个文件（新文件会被删除，需确认），填写说明后提交（未暂存任何文件时提交全部改动；Ctrl+Enter 提交）。不会推送到远程。项目是仓库子目录或仓库尚无提交时也可使用。

### v0.12.0：界面架构重构
界面从 7 个共享全局变量的脚本改为 ES 模块，主窗口通过受限的 `app://desk/` 协议加载（只开放 `ui/` 和 marked、DOMPurify 两个库）。依赖只朝一个方向：

- `ui/src/core`：DOM 工具、状态格式化、状态仓库（事件订阅）、提示条与确认框。
- `ui/src/lib`：纯函数（过程拆分、工具行、行级 diff、速度统计），不访问 DOM，可在 Node 中测试。
- `ui/src/features/actions.mjs`：选择会话、发送 / 排队、删除、重命名等全部业务动作，只通过参数拿到 api、仓库和输入框接口，不访问 DOM。
- `ui/src/views`：侧栏、对话、单轮、状态栏、输入框、右侧面板、改动审查、管理窗口、分栏和窗口外框，各自订阅仓库事件，不互相读写。
- `ui/src/main.mjs`：创建并连接以上模块。

渲染改为增量更新：每轮对话是持久的 DOM 节点，只有版本号变化的轮次、内容变化的步骤才会重写；`<details>` 元素保留，展开状态和过渡动画不会被打断。主进程为每轮生成版本号快照，已结束的轮次复用缓存，只把变化的轮次发给界面（未变化的只发 `{id, rev, same}`）。样式由 `scripts/merge-css.cjs` 合并为 `ui/app.css`：按原层叠顺序删除被同一选择器后续完全覆盖的 298 条声明，合并前后计算样式逐项一致。

### v0.13.0：动画
只有新出现的内容会动：运行中新追加的步骤和新的一轮上浮淡入，最终回复开始出现时淡入，一轮结束时过程组平滑收起、改动汇总和底栏依次浮现；切换会话时整页淡入，历史内容不逐条重播。过程组、步骤、思考和子智能体卡片的展开收起是高度过渡（CSS `::details-content`）。菜单、模型 / 权限选择、对话框、提示条、批准卡片、排队列表、子智能体分栏有出现动画；按钮有悬停和按压反馈，图标栏名称提示延迟淡入。系统开启「减少动画」时全部关闭。动画样式集中在 `ui/app.css` 末尾的 Motion 分区，时长和缓动曲线是 `--motion-*` 与 `--ease-*` 变量。

### v0.25.0：更新包
- **发布**：`npm run package` 之后运行 `npm run release`，在 `outputs/releases` 里生成完整包 `ClaudeDesk-<版本>-win-x64.zip`（带使用说明），并和上一个版本比较，生成只含变化文件的更新包 `ClaudeDesk-<旧版本>-to-<新版本>-update.zip`。每个版本的文件清单（SHA-256）保存在 `outputs/releases/manifests`，作为下一次的对比基准；`--from <版本>` 可以指定基准。平时只有 `resources/app.asar`（约 19 MB）会变，更新包只有几 MB；内置的 Claude Code 和 Electron 运行时只有升级时才进更新包。
- **安装**：设置 → 安装更新包，选择 zip。Claude Desk 先解压到 `data/updates` 并检查：是不是 Claude Desk 的更新包、是不是给当前版本用的、每个文件的 SHA-256、路径不能出程序文件夹。确认后 Claude Desk 关闭，安装脚本等它退出后替换文件、删除不再需要的文件，再把它打开；结果写在 `install.log`，下次启动时如果上次失败会提示，并清理临时文件（`updates.cjs`）。开发版不能安装更新包。
- 更新包也可以手动用：关闭 Claude Desk，把压缩包里的文件解压到程序文件夹覆盖（包里的「怎么安装.txt」有说明）。0.24.1 还没有「安装更新包」按钮，从 0.24.1 升级要用手动的办法。
- **exe 不进更新包**：打包工具会把 app.asar 的哈希写进 ClaudeDesk.exe，导致每次改代码 exe（约 250 MB）都跟着变。Electron 只在 EnableEmbeddedAsarIntegrityValidation 开关打开时才检查这个哈希（现在是关的），所以 `npm run package` 会沿用同一个 Electron 版本和图标第一次打出的 exe（`outputs/releases/exe-cache`）；开关被打开时自动停止沿用。exe 文件属性里的版本号因此停在 0.24.1，Claude Desk 自己显示和更新包检查的版本来自 app.asar 里的 package.json。

- 内置的 Claude Code 不再直接放在程序文件夹里：打包时用 zstd 压缩成 `resources/claude-code/claude.exe.zst`（298 MB → 102 MB，压缩结果缓存在 work/claude-code），只有选择「使用内置版」才解压。已经解压过的，以后更新包带来新版本时自动替换。
- 从 0.25.x 升级的更新包这一次约 100 MB（要带上压缩后的内置版）；原来放在 app.asar.unpacked 里的 claude.exe 会被删除。之前在用内置版的人，升级后会看到环境窗口，点「解压并使用内置版」即可。

### v0.26.1：导入不再限制 512 MB
- 去掉 Claude Code 和 Codex 导入的 512 MB 限制（单个日志和一次多选合计都去掉了）。Codex 的压缩日志（.jsonl.zst）改为边解压边逐行读，不再整份解压成一个字符串；Claude Code 日志读取时就丢掉图片数据。
- 唯一剩下的上限是导入后单条会话存成 JSON 后约 512 MB（JavaScript 单个字符串的上限）；碰到时导入会撤销并提示「会话太大」。

### v0.27.0：分块存储与 Windows 文件占用修复
- SQLite 格式升级到 v2：会话元数据、每轮问答和用量分别保存，记录内部按有界 token 流分块，读取时直接重建对象。一整条会话或一轮问答不再需要变成单个 JSON 字符串；仍受机器内存和单个 JavaScript 字符串字段的限制。
- 首次打开旧数据库时先用 `VACUUM INTO` 创建 `migration-v1-backup-*.sqlite` 独立备份（包含已提交 WAL），再在事务内迁移，保留会话、轮次、来源 ID、顺序、草稿和用量；失败回滚，不清空旧数据。旧版无法读取 v2；回退须先退出所有实例，再从迁移备份恢复，并保留新版数据库以免丢失迁移后的消息。
- 独立会话镜像和全量 JSON 备份使用流式写入；未修改的问答不重写。重启续聊仍沿用原有末尾 120,000 字符预算，但不再先序列化全部历史。界面仍全量加载，原生 CLI 会话恢复机制不变。
- 项目文件、改动统计、存储统计和更新校验使用不解释 ASAR 的原始磁盘接口；文件列表跳过 `.asar`，归档预览显示为二进制。浏览项目构建产物或校验更新包不会再缓存归档句柄；应用自身的 ASAR 加载保持开启。
- 更新失败保留原始校验错误，暂存清理遇到占用时报告路径而不覆盖原错误；外部 CLI 和安装入口隐藏中间启动进程的窗口。旧版本若安装更新报 `EPERM`，这次先退出软件、手动解压对应更新包覆盖一次，之后使用新版内置更新。

### v0.28.0：独立更新器
- 程序文件夹新增 `ClaudeDesk.Updater.exe`（用 Windows 自带的 C# 编译器生成，约 23 KB），替代原来的 PowerShell 安装脚本。安装时先复制到暂存目录再运行，所以更新包也能替换更新器本身。
- 更新器校验完更新包、写出就绪标记后 Claude Desk 才退出；校验失败或启动失败时程序不关闭并显示原因。主程序退出后先备份将被替换的文件，再逐个原子替换，装完核对每个文件的哈希和 `claude-desk-version.json` 里的版本，任何一步失败都恢复旧文件。回滚也没完成时备份目录会保留，下次启动提示其位置。
- 拒绝越出程序目录的路径、链接目录和保留文件名；等待主程序退出超时只放弃安装，不结束主程序。

### v0.28.1：输入时不再一直显示“正在保存”
- 保存草稿只写设置、项目和草稿这一条记录（`DatabaseStore.saveState`），不再给每一轮问答重算指纹；也不再强制同步磁盘（断电最多丢最后几次输入，数据库不会损坏）。在正式数据的快照上从约 50 毫秒降到约 1 毫秒，且不随会话变大而变慢。
- 打字时不再先显示“正在保存…”，只有一次保存超过 0.6 秒才显示。

### v0.29.0：插话、托盘、服务商与大会话
- 插话：任务运行中按 Enter 发送的消息不再排队，而是带 `priority: 'next'` 写入正在运行的 Claude Code，在下一步之前交给 Claude，任务不停止。输入框上方显示「插话 · 等待当前步骤完成」，读到后作为「你插话」出现在本轮步骤里。CLI 在回复里标明已读时立即确认；没标明的在本轮结束时按已读处理，若 CLI 结束后又接着回复，就拆成单独的一轮（带「插话」标记）。停止或失败时未送达的插话放回队列。Tab 仍加入队列；排队的消息也可以点「插话」。
- 托盘：右下角常驻 Claude Desk 图标，菜单可打开窗口、新建任务、跳到运行中的会话（等你处理的带 ⚠）、退出。关闭窗口默认隐藏到托盘，任务继续运行，第一次会发通知说明；设置 › 通知与电源可关掉「关闭时留在托盘」。
- 启动提速：打开或在空闲会话里打字时，用 Agent SDK 的 `startup()` 先启动这个会话的 Claude Code（模型、权限、思考强度、扩展、提示词、服务商都与输入框一致才会被采用，否则关掉重启），发送时省掉 0.7–5 秒的启动时间。最多同时等两个，四分钟不用就关闭。
- 服务商：设置新增「服务商」页，可添加兼容 Anthropic 接口的服务商（名称、Base URL、Auth Token 或 API Key、模型列表、可选快速模型），点一下切换，从每个会话的下一条消息生效。密钥用 Electron `safeStorage`（Windows DPAPI）加密保存，界面只拿到名称、地址和模型；运行时通过环境变量和 `--settings` 的 env 传给 CLI，优先于 `~/.claude/settings.json`。选回「Claude Code 自己的配置」即恢复原来的行为。
- 大会话：流式输出时每秒做一次轻量保存，只处理有变动的会话、用 WAL 的 NORMAL 同步、不重写 JSON 副本；在 4 MB 的真实数据上从每次 150–400 毫秒降到约 12 毫秒，本轮结束等操作仍是完整保存。实时快照按工具缓存，不再每次深拷贝整轮。超过 30 轮的会话先显示最近 30 轮，顶部「显示更早的 N 轮」或滚到顶部继续加载。
- 改动卡片：每轮下方显示「已编辑 N 个文件 +x −y」，前三个文件按目录灰、文件名亮显示，其余收在「再显示 N 个文件」里；「撤销」把这一轮改过的文件恢复到这一轮开始前的快照（会提示之后几轮是否也改过这些文件），对话保留，可以「重做」；「查看变更」打开审查面板。
- 提问卡：多个问题分页显示，顶部标签可跳转并标记已回答，单选后自动到下一题，上一个 / 下一个 / 提交回答，数字键 1–9 选选项；选项描述完整显示，不再被截断。
- 回到最新：在长会话里往上翻超过约半屏时，消息区底部出现圆形向下箭头，有新内容时带圆点。
- 子智能体面板：运行中的保持卡片，结束的收进一行「已结束 N 个」，展开是一行一个的简表（任务名和耗时），点击在分栏查看。
- 粘贴图片：缩略图立即用原图显示，读取数据和生成缩略图改在后台（`createImageBitmap` 在主线程外解码），发送时等它们完成。
- 不再每条消息都像在“重启”：会话一直复用同一个 Claude Code 进程，状态栏只在真正冷启动时显示「正在启动 Claude」，否则是「正在记录文件快照」→「已发送，等待模型响应」。文件超过 4 万个、无法做快照的文件夹十分钟内不再重复列文件（原来每条消息白等约 2 秒）。
- 上下文明细：点上下文圆环，除了总量还按类别显示（系统提示词、内置工具、MCP 工具、记忆文件、技能、对话消息、自动压缩预留、剩余空间），以及各 MCP 服务器和记忆文件的占用，数据来自 CLI 的 `getContextUsage()`；「详细分析」逐项精确计数；「压缩上下文」发送 `/compact`，完成后在回复里写明压缩前后的 tokens。CLI 没报告上下文上限时也用它补上。
- ＋ 菜单（参考 Codex）：图片、项目文件（@）、其他会话（@@）、计划模式开关、当前项目可用的技能（插入 `/技能名`）和「管理插件和技能」；单独的图片按钮去掉。
- 连续的同类步骤合并成一行，例如「运行了 4 个命令」「读取了 3 个文件」，中间的思考一起收进去，点开看每一步；运行中显示「正在运行命令 · 已 N 步」。
- 右键菜单：输入框里有撤销、重做、剪切、复制、粘贴、全选（拼写建议在最前）；选中文字可复制或「引用到输入框」；链接可复制地址或用浏览器打开；图片可复制。
- 提示气泡移到窗口上方，不再挡住输入框。
- 运行状态显示在这一轮里原来「正在处理」的位置，例如「等待模型响应 · 41s　工具已返回，等待模型继续」，超过 25 秒没有事件时说明可能在等服务商。输入框上方的状态条只在往上翻、看不到正在运行的那一轮时出现；去掉了「停止运行」按钮，停止用输入框右下角的停止键（输入框为空时）。
- 带网关前缀的模型 ID（如 `ocx-claude-claude--claude-opus-5-5`）在选择器里显示为「Claude Opus 5.5 · ocx-claude-claude」，和不带前缀的条目区分开。服务商自己命名的模型排在最前（其中 Claude 系列在前），不带前缀的 `claude-…` 通用名称放到后面一组，并注明可能被网关转到其他服务商。
- 更新包安装成功后，下次启动时把那个 zip 移到回收站（提示「已更新到 …，更新包已移到回收站」）。只处理这次装的那个文件，而且大小和修改时间要和安装时一致；安装失败或文件被替换过就不动。
- 去掉输入框下方的「已自动保存」，只在保存变慢或失败时提示。输入框的「提示词」按钮移除：全局提示词在设置 › Claude，项目提示词在项目右键菜单，会话右键菜单也能直接打开。
