关于与更新
版本
自动安装启动后检查 GitHub 新版本，每小时再检查一次。倒数 10 秒后自动下载并安装，可以取消；有任务在运行就等它们结束
更新设置
接收预览版更新包含 Beta、RC 等测试版本，可能不稳定。关闭后等待更新的正式版，不会自动降级。保存后生效
手动安装更新包放在别处时，直接选择那个 zip 文件


扩展与用量
为 Claude 配置能力，查看本地累计使用情况


提示词
加在 Claude 的系统提示词后面，例如回答风格、要遵守的规范、项目背景。保存后从每个会话的下一条消息开始生效（Claude 会重新启动并带上之前的对话）。项目提示词和全局提示词冲突时以项目为准。
添加 MCP 服务器
填写单个服务器配置，支持 HTTP、SSE、WebSocket 和 stdio。也可填写 command、args、env、headers；凭据保存在 Claude CLI 配置中。添加不代表批准项目服务器。
